## Requirements

Python 3.10+ is recommended. This lab uses only the Python standard library.

## Run the rule-based example

```bash
cd lab1
python lab1_rules.py
```

The program runs exactly four core test cases and prints the input, expected
result, actual result, and reason.

## Run the comparison example

```bash
python lab1_compare.py
```
